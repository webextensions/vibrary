# because/

Why-documentation for hacks, workarounds, and non-obvious decisions in this project (see
"Non-Obvious Decisions" in [.claude/rules/git-workflow.md](../.claude/rules/git-workflow.md)).

- One markdown file per decision, named after the thing it explains.
- Each file explains why the approach was taken - the constraint, the alternatives rejected, and
  what would have to change for the workaround to become unnecessary.
