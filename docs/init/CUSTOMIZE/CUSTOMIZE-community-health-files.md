# Community health files

Applies to: new project only.

- [`SECURITY.md`](../../../SECURITY.md) points reporters at GitHub private vulnerability reporting.
  Enable that for your repository (SECURITY.md documents where the setting lives). The file itself
  is shared template content - leave it to receive template updates conflict-free.
- [`CONTRIBUTING.md`](../../../CONTRIBUTING.md) is generic on purpose (it points at `README.md` /
  `AGENTS.md` / `docs/` for project specifics) - it needs no per-fork edits, so leave it to receive
  template updates conflict-free.
