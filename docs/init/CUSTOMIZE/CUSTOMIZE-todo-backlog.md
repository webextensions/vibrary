# TODO backlog

Applies to: both flows.

[`docs/specs/todo/TODO.md`](../../specs/todo/TODO.md) is the fork's own task list (see
[docs/template-project/file-conventions.md](../../template-project/file-conventions.md)):

- A new layer branch keeps `TODO.md` as the generic skeleton and adds its own backlog as a sibling
  `TODO-for-<your-branch>.md` in the same folder.
- A new project owns `TODO.md` directly - replace the skeleton with your project's task list.
