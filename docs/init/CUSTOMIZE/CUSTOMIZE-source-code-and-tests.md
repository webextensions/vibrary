# Source code and tests

Applies to: new project, and template branches that introduce a layout.

The base branch ships no runnable source code - add your project's own layout (the template
branches, e.g. `template-npm-package-for-exports`, demonstrate concrete layouts). Replace the placeholder
[`./test/sanity.test.js`](../../../test/sanity.test.js) with real tests (conventions:
[testing.md](../../../.claude/rules/testing.md)).
