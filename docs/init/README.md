# Initializing a new branch or project

Steps to take once, right after creating a new branch or project forked from the
`template-javascript-project` family (vision and branching tree:
[docs/template-project/README.md](../template-project/README.md)).

- [CUSTOMIZE/](./CUSTOMIZE/) - the customization checklist, one `CUSTOMIZE-*.md` file per step:
  start at [CUSTOMIZE/README.md](./CUSTOMIZE/README.md) and follow the steps whose "Applies to:"
  line matches your flow (new layer branch / new project).
